# Otter & Co. website

Static HTML website for Vercel or GitHub Pages.

## Files
- `index.html` — main site, pricing and budget calculator
- `page-audit.html` — interactive 10-point client self-assessment (not automatic URL scraping)
- `otter-logo.svg` — supplied logo
- `otter-logo.svg` — site icon
- `vercel.json` — static Vercel configuration

## Deploy on Vercel
1. Create an empty repository on GitHub and upload these files to its root.
2. Import that repository into Vercel (Framework: Other; build command blank; output directory blank).
3. Deploy and verify navigation.

## Before launch
- Contact form currently prepares/copies enquiry text, without transmitting it. Configure an authenticated form endpoint or official business WhatsApp address.
- Add approved real portfolio work, verified testimonials, business contact details, privacy policy and domain/canonical URL.
- Page audit is self-assessment, no social-media APIs or claims of automatically inspecting a profile.
- Verify pricing and media budgets with final quotation.
